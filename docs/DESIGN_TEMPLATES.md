# 디자인 템플릿 사용법

프로젝트 루트의 `design-templates/`에 템플릿을 폴더별로 모아둡니다. 에이전트에게 폴더 이름을 말하면 해당 자료를 기준으로 현재 사이트의 코드를 수정합니다.

## 템플릿 추가

1. `design-templates/` 안에 원하는 이름의 폴더를 만듭니다. `_template/`을 복사해 시작해도 됩니다.
2. 스크린샷, HTML/CSS, React 소스, 이미지·폰트 등 가지고 있는 디자인 자료를 넣습니다. ZIP은 압축을 풀어 넣어주세요.
3. 참고 사이트나 Figma 링크, 반영할 부분은 해당 폴더의 `README.md`에 적습니다. 파일만으로 디자인을 확인할 수 있다면 README는 생략해도 됩니다.

```text
design-templates/
├── README.md
├── _template/                 새 템플릿용 양식
│   └── README.md
├── magazine/                  예시 이름
│   ├── README.md              참고 링크와 디자인 메모 (선택)
│   ├── screenshots/           PC·모바일 화면 (선택)
│   ├── source/                HTML/CSS 또는 React 원본 (선택)
│   └── assets/                이미지·아이콘·폰트 (선택)
└── minimal/                   다른 템플릿 예시 이름
    └── home.png
```

`magazine`과 `minimal`은 구성 예시입니다. 실제로 쓸 템플릿 폴더를 추가하면 됩니다. 하위 폴더 구성은 자유이며, 디자인을 확인할 수 있는 자료나 접근 가능한 링크가 하나 이상 필요합니다.

## 적용 요청

폴더 이름을 그대로 사용합니다. 한글 폴더 이름도 가능합니다.

```text
magazine 템플릿 적용해줘.
```

기본 범위는 전체 사이트입니다. 공통 헤더·푸터, 홈, 목록·상세, 검색, 안내 페이지와 모바일 화면에 디자인을 맞추며, 기존 기능·데이터·주소와 한국어 콘텐츠를 유지합니다.

일부 화면만 바꾸거나 특정 요소를 지정할 수도 있습니다.

```text
minimal 템플릿으로 홈 페이지만 바꿔줘.
magazine 템플릿을 적용하되 색상은 현재 것을 유지해줘.
```

다른 템플릿 이름으로 다시 요청하면 그 자료를 기준으로 디자인을 재작업합니다. 원본 템플릿은 보관함에 유지합니다.

## 보관 위치와 코드 검사

현재 적용한 디자인은 `luma`입니다. 크림색 배경, 먹색 버튼, 중앙 제목과 주변 표지 배치를 서울시티의 검색·가이드 구성에 맞게 재구현했습니다.

- 공통 색상·글꼴·반응형 스타일: `src/app/globals.css`
- 홈 첫 화면: `src/components/HomeHero.tsx`
- 가이드 표지·행사 포스터: `src/components/design/`
- 먹거리 목록·구별 상세: `src/app/food/`, `src/app/districts/[slug]/food/`, `src/components/food/`
- 공통 탐색: `src/components/Header.tsx`, `src/components/Footer.tsx`

디자인은 기존 Next.js 코드에 적용되며, 템플릿 폴더 이름으로 변경을 요청할 때마다 해당 자료에 맞춰 코드를 수정합니다.

`design-templates/`는 디자인 참고 자료를 보관하는 곳입니다. 실제 적용 코드는 기존 `src/app`, `src/components`, 스타일 파일에 반영합니다.

이 폴더는 TypeScript와 ESLint 검사에서 제외되어 다른 프로젝트의 소스를 함께 보관할 수 있습니다. 사이트에 사용할 이미지·폰트는 필요한 파일만 `public/` 등 앱에 맞는 위치로 옮겨 사용합니다. 템플릿은 사용 권한을 확인한 자료를 보관하고, 의존성 폴더나 빌드 산출물, API 키·환경변수 파일은 제외하세요.
