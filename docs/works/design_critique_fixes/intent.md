## 문제와 배경

2026-11-02 운영 사이트 디자인 검사에서 화면 모양보다 먼저 신뢰 문제가 드러났다.

| 문제 | 확인한 원인 |
| --- | --- |
| 홈 첫 화면의 ‘아이와’ 바로가기가 검색 결과 0건 | 검색은 모든 단어가 맞아야 결과에 넣는다. `서울 아이와 갈만한 곳`에서 ‘갈만한’·‘곳’이 결과를 막는다. 검색창 예시 문구 `성동구 무료 전시`도 0건이다 |
| ‘이번 주 마감 혜택’ 링크가 늘 빈 목록 | 혜택 1,103개 중 마감일이 정해진 혜택은 10개뿐이고, 2026-11-02 기준 가장 가까운 마감일이 2026-12-18이다 |
| 구 페이지에 다른 구 혜택이 나옴 | 글 안에 ‘서울’만 있어도 서울 전체 혜택으로 통과시키는데, 모든 기관명이 ‘서울특별시 ○○구’라 전부 통과한다 |
| 구 페이지 숫자가 홈 지도와 다름 | 상단 수치가 전체 개수가 아니라 화면에 보여주는 최대 6·3·4개를 센 값이다. 행사는 글자 포함으로 골라 중구 페이지에 중랑구 행사가 섞인다 |
| 행사·혜택 데이터가 비면 개발자용 명령어가 보임 | 데이터 없음 화면이 수집 스크립트 실행 안내를 그대로 보여준다. [보안 규칙 7절](../../../.agents/rules/SECURITY_RULES.md)의 공개 화면 운영 정보 노출 금지에도 걸린다 |

## 기대 결과

- 홈에서 권하는 첫 클릭이 빈 화면으로 끝나지 않는다.
- 구 페이지는 그 구의 정보만 보여주고, 숫자가 홈 지도·목록 페이지와 같다.
- 데이터가 비어도 사용자에게 내부 운영 정보를 보이지 않는다.
