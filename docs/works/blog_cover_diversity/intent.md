## 문제와 배경

블로그 표지를 글자 없는 일러스트로 바꾼 뒤, 서로 다른 글에서도 같은 그림이 반복되어 목록의 시각적 구분이 부족하다. 독자가 표지만 보고 글의 주제와 분위기를 구별하기 어렵다.

2026-10-21 로컬의 `public/blog-covers/*.svg` 181개를 확인한 결과다.

| 항목 | 현재 상태 |
| --- | --- |
| 표지 수 | 181개 |
| 기본 그림 종류 | 7종 |
| 산책 그림 사용 | 98개, 전체의 약 54% |
| 그림·배색 조합 | 32개 |
| 가장 많이 반복된 동일 조합 | 21개 글에서 사용 |

조합 수는 SVG의 접근성 설명인 `<title>`과 `<desc>`를 제외한 나머지 내용을 비교한 값이다. 색만 다른 그림도 별도 조합으로 계산하므로, 사람이 느끼는 반복은 이 수치보다 클 수 있다.

현재 생성기는 음악·책·카페·비·음식·미술·산책의 7가지 그림을 사용하고, 키워드에 해당하지 않는 글에는 산책 그림을 배정한다. 배경과 사물 위치도 같아 색상 변화만으로는 반복감을 줄이기 어렵다.

## 대상 사용자

홈 추천 글과 블로그 목록에서 서울 생활 정보를 탐색하는 독자다. 여러 글을 훑어보며 관심 있는 주제를 고를 때 표지가 탐색을 도와야 한다.

## 기대 결과

- 서로 다른 주제의 글이 표지에서도 구별된다.
- 같은 주제의 글도 장면과 구도가 달라 목록에서 반복감이 줄어든다.
- 개별 표지는 다양해지면서 서울시티의 일관된 분위기를 유지한다.
- 기존 글을 개선하고, 앞으로 생성되는 글에서도 같은 문제가 누적되지 않게 한다.

## 개선 범위

- 기존 표지 181개의 주제 적합성과 반복 문제
- 앞으로 생성되는 블로그 글의 표지 다양성
- 홈 추천 글과 블로그 목록에서 표지가 함께 보일 때의 인상

사이트 전체 리디자인, 글 본문 이미지 추가, 원문 내용 수정은 이번 개선 범위에 포함하지 않는다.

## 유지할 조건

- 이전에 합의한 글자 없는 일러스트와 크림색 바탕·차분한 색감을 기준으로 삼는다.
- 표지에 제목·태그를 다시 넣지 않고, 카드 아래의 짧은 제목과 현재 글꼴 스타일을 유지한다.
- 원문 제목·본문·슬러그·이미지 경로를 보존한다.
- 사용자 지정 이미지가 있다면 자동 교체 대상에서 제외한다.
- 색상 변경이나 같은 그림의 반전·확대만으로 다양화가 완료되었다고 판단하지 않는다.
